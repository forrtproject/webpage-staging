COVCOG 2: Cognitive and Memory Deficits in Long COVID: A Second Publication From the COVID and Cognition Study

Panyuan Guo, Alvaro Benito Ballesteros, Sabine P. Yeung, Ruby Liu, Arka Saha, Lyn Curtis, Muzaffer Kaser, Mark P. Haggard, Lucy G. Cheke

Frontiers in Aging Neuroscience, 2022. DOI 10.3389/fnagi.2022.804937

Has this study been replicated?

The atlas records 1 replication of this study. Recorded outcomes: 1 mixed. The earliest on record is from 2025.

Replications

  • Changes in memory function in adults following SARS-CoV-2 infection: Findings from the Covid and Cognition online study, Weinerova et al. (2025). Cortex. Outcome recorded: mixed. We have found previously reported effect of Covid status on accuracy in 2 long-term memory tasks (verbal item memory task and nonverbal associative memory task), but did not replicate previously reported effect on reaction times. Outcome read from the abstract. View paper
